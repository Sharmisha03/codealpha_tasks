# 📈 Task 2: Stock Portfolio Tracker

## 📌 Description
This project is a simple stock portfolio tracker developed using Python.  
It allows the user to input stock names and quantities, calculates total investment based on predefined stock prices, and optionally saves the result to a file.

---

## 🚀 Features
- User input for stock name and quantity
- Predefined stock prices using dictionary
- Calculates total investment value
- Input validation for stock names
- Option to save output to a file

---

## 🧠 Concepts Used
- dictionary
- input/output
- while loop
- if-else conditions
- basic arithmetic
- file handling

---

## ▶️ How to Run
1. Open terminal  
2. Run:

```
py task2_stock_tracker.py
```
